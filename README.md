# MVP de Machine Learning & Analytics - Sprint 1

Este repositório contém o MVP desenvolvido para a Sprint 1, focado na criação de um pipeline automatizado para a detecção de intrusões e anomalias de segurança em redes de Internet das Coisas (IoT).

O notebook foi desenvolvido e homologado para rodar diretamente no ecossistema do Google Colab. Para executar os experimentos, visualizar as tabelas comparativas de custo computacional e a matriz de confusão final, basta acessar o link abaixo:
